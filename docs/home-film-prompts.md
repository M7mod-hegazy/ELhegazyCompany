# ElHegazi Home Film — "One Take" Generation Pack (v2 — الحجازي wordmark)

Everything below is written for **Gemini / Flow (Imagen for stills + Veo for motion)**.

**Workflow per clip:** generate the **START frame** and **END frame** as images first, then feed
both into Veo with the **MOTION** prompt. Aspect **16:9**, ~**5 seconds** per clip, cinematic
**24 fps**.

**Every prompt below is complete and self-contained** — copy-paste any single block on its own;
nothing refers to a shared style section.

**The seam rule (what makes it read as one take):** the END frame of each clip is reused as the
START frame of the next clip, and every join happens inside a bloom of gold light so the cut is
invisible. Generate the 6 unique keyframes first (Clip 1 start, the 4 seam frames, Clip 5 end),
then animate each clip between its two frames.

**The text rule (critical — the website writes on top of the film):** the site scroll-scrubs this
film and overlays live HTML text on it. Each clip below states exactly which area of the frame
must stay as clean, dark, low-detail negative space. Do not let bright highlights, faces, busy
props, or the seal itself sit inside that reserved area. The reserved areas are:

| Clip | Site copy that will overlay | Reserved clear zone (physical, 16:9 frame) |
|---|---|---|
| 1 intro | Headline + lead + two buttons, centered | **middle of frame** (center 50% width, middle 60% height) |
| 2 marketing | Chapter title + line + button | **bottom-left quarter** |
| 3 pos | Chapter title + line + buttons | **bottom-right quarter** |
| 4 ecommerce | Chapter title + line + buttons | **bottom-left quarter** |
| 5 outro | CTA title + subtitle + two buttons | **bottom-right quarter** |

## THE الحجازي SEAL (the only logo allowed anywhere in the film)

Where a prompt says **"the الحجازي seal"**, it means exactly this, described in full inside each
prompt already: *a circular emblem like a wax seal, struck in polished brass with fine engraving;
at its centre the Arabic word **الحجازي** rendered in elegant Diwani/Thuluth calligraphy, slightly
raised, catching a warm specular highlight; a thin concentric ring frames the word, with tiny
geometric Islamic guilloche detailing around the rim. It reads as a heritage maker's mark — a
stamp of authorship, not a corporate logo.*

## Deliverables & drop-in instructions

1. **Generate the 6 unique keyframes first** (Clip 1 START, the 4 seam frames, Clip 5 END), then
   animate each clip between its two frames. Reusing the exact seam image on both sides of a cut
   is what makes it read as one take.
2. **Concatenate the 5 clips in order** and encode **all-keyframe** so scroll-scrubbing is
   frame-accurate and smooth:

   ```bash
   # put clip1.mp4 … clip5.mp4 in one folder, then:
   printf "file 'clip1.mp4'\nfile 'clip2.mp4'\nfile 'clip3.mp4'\nfile 'clip4.mp4'\nfile 'clip5.mp4'\n" > list.txt
   ffmpeg -f concat -safe 0 -i list.txt -an -c:v libx264 -preset slow -crf 23 \
          -g 1 -pix_fmt yuv420p -movflags +faststart home-film.mp4
   ```

   Aim for **≤ 25–30 MB total**; if larger, raise `-crf` (25–28) or scale to 1600×900.
3. **Drop the file at** `public/films/home-film.mp4` — the home page picks it up automatically
   (the placeholder film currently at that path gets replaced; no code change needed).
4. **Poster stills**: export each clip's START frame as JPG →
   `public/posters/home/{intro,marketing,pos,ecommerce,outro}.jpg`
   (used for the pre-load poster and the reduced-motion/mobile fallback).
5. Optional later: 9:16 vertical variants of each clip for a dedicated mobile film.
